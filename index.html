The Jinx Wiki

1. Overview

Jinx is an imperative-syntax, functional-core programming language designed to translate high-level code directly into simplified slot-based bytecode instructions.

It is NOT an esolang (see Esoteric Languages Wiki). Rather, it relies on Lambda calculus principles (see Wikipedia's Lambda Calculus entry).

Core Architecture: High-level variable names exist only during compilation. At runtime, execution boils down to a 256-slot register table, dynamic structs, and fast reductions.

How to Run a Script

Place rdX.exe in your project directory and run your script from the terminal:

# 1. Create a file named program.rdX
input_str name
let greeting = "Hello "
print_str greeting
print_str name

# 2. Run it with rdX
rdX.exe program.rdX

3. High-Level Language Syntax

Reduction source files (.rdX) support variables, console I/O, linear math, functions, and explicit deallocation.

Variables & Strings

let x = 4
let greeting = "Hello World"

Math Operations

let z = x + y
let product = x * y

Lambdas & Calls

function double(n) = ADD n n
run double(total) -> result

Memory Management

free x

4. Bytecode Opcode Reference

The compiler maps variable names to slot indexes (e.g., slot 1, slot 2) and generates these instructions:

Instruction Arguments Description
IN / IN_STR [slot] Prompts user input and assigns integer or string to target slot.
OUT / OUT_STR [slot] Prints integer or string value stored in the slot to stdout.
SET / STR [slot] [val] Stores an immediate integer or string literal in target slot.
ADD / MULT [s1] [s2] [dest] Performs math across source slots and outputs to destination slot.
LAMB [slot] (param) -> op Registers a lambda signature in target memory slot.
lamb [func] [arg] [dest] Executes stored lambda operation using argument slot.
FREE [slot] Deallocates pointer memory reserved for the given slot.

5. C++ VM Engine

The backend Virtual Machine (RDXVM) manages dynamic types using tagged Register structs across 256 default slots. 

enum ValueType { INT_VAL, STRING_VAL, LAMBDA_VAL };

struct Register {
    ValueType type;
    int intVal = 0;
    std::string strVal = "";
    Lambda lambdaVal;
};

6. Memory Allocation & Cleanup

Reduction avoids garbage collection overhead by relying on deterministic deallocation. When free x is invoked in high-level code, the compiler emits a FREE [slot] instruction which immediately deletes heap pointers in C++: 

else if (op == "FREE") {
    int slot; ss >> slot;
    if (slots[slot]) { delete slots[slot]; slots[slot] = nullptr; }
}
